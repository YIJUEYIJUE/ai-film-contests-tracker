# AI赛事助手 · 数据规范（v6）

## 1. 数据来源与权威链

- 权威底表：飞书多维表格「AI赛事」表（人工维护）。
- 每日快照：`data/contests_YYYY-MM-DD.json`、`festivals/festivals_YYYY-MM-DD.json`。
- 站点只读快照构建，**不直接改网页数据**；结构改动必须先改底表。

## 3. 字段取值约定

| 字段 | 允许取值 | 禁止 |
|---|---|---|
| 分级 | `S` `A` `B` `C` | 空值、其他字母 |
| 征集状态 | `开放征集中` `待公布` `即将开放` `已截止` | 自由描述 |
| 截止日期 | `YYYY-MM-DD` 或空 | 相对时间、"待定"写在日期里 |
| 命题 | `命题` `自由投稿` 或空 | 其他文字 |
| 报名费 | 具体金额 / `免费` / `官方未公布` / `未核实` | 臆测金额 |
| 官网 | 主办方官方域名 | 聚合站（投奖、aitop100 等） |
| 投递链接 | 官方 submit > 官方 FF/Festhome > 邮箱 | 有官方入口时填聚合站 |

**多档截止取最后一档**；通知日、影展日不是截止日，不得写入。

## 4. 派生的核实状态

构建时按下表生成每条赛事的核实徽章：

| 值 | 含义 | 判定 |
|---|---|---|
| `ok` | 官网已核实 | 修正层里有 `verify.level = ok` |
| `fixed` | 已按官网更正 | `verify.level = fixed` |
| `warn` | 需要你再确认 | `verify.level = warn` |
| `none` | 未自动核实 | 无记录（通常是聚合站页面或需登录的页面） |

修正层文件 `scripts/overrides.json`：

```json
{ "records": { "recXXXX": { "fix": { "报名费": "€20–30" }, "verify": { "level": "fixed", "note": "原表写 $15–25，官网为 €30" } } } }
```
构建时先应用 `fix`（覆盖原字段），再写入 `verify`。上游数据更新后修正不会丢。

## 5. 质量校验（构建时执行，违反即中止或告警）

中止（不发布）：
- 记录数为 0
- 记录数比上一版减少超过 30%
- 超过 5% 的记录缺少 `名称` 或 `record_id`

告警（可发布，写入构建日志）：
- 截止日期格式不合规（自动置空）
- 分级不在枚举内（降为 C）
- 已过截止日但状态仍为征集中
- 官网/投递链接为空，或指向聚合站
- 报名费/最高奖金为空

## 6. 每天维护流程

1. 巡检信源，发现新赛事或变更。
2. 打开主办方官网逐字段核对（名称、主办方、截止、官网、投递、报名费、奖金、资格）。
3. 写底表；同步当日快照；重建站点。
4. 已过截止 7 天以上的条目移除；S/A 级移除前必须先确认官方是否延期。
5. 实质变更记入变更记录。
