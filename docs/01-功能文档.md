# AI赛事助手 · 完整功能文档（v6 重写版）

> 本文档是**唯一需求来源**。新代码只按本文档实现，不参考旧版任何代码。
> 旧版问题（记录在案，禁止重演）：以「我的作品库」为主线、首页出现「我的赛事」、页面里出现「数据来源于 xx」链接、信源页暴露内部字段、组件堆叠过密、筛选在手机上排版破损。

---

## 0. 定位

**一句话**：把散落在各处的 AI 影像赛事收成一张随时可查的表，并告诉你"哪些现在能投、什么时候截止"。

**目标用户**：用 AI 做视频的创作者（独立导演、短片/短剧作者、广告与动态设计、影视院校学生、小工作室）。

**核心原则**

1. **赛事是唯一主线**。首页第一屏必须是赛事本身（数量、最近的截止、值得投的），不允许出现个人作品、个人进度之类的内容。
2. **不做个人作品库**，不做投递看板，不做资料卡。用户的片子不在这个站里管理。
3. **只展示对用户有用的信息**，不展示站点自己的数据来源、内部字段、采集方式。
4. **数据以官方页为准**，凡是我们自己不确定的，必须明确标出来。

## 2. 数据模型

### 2.1 赛事字段（每条赛事必须有）

| 字段 | 类型 | 说明 | 界面位置 |
|---|---|---|---|
| `id` | 字符串 | 唯一标识 | 内部 |
| `name` | 字符串 | 赛事全称，多单元写明单元名 | 卡片主标题 |
| `grade` | `S/A/B/C` | 分级 | 色块徽标 |
| `deadline` | `YYYY-MM-DD` 或 `null` | **取最后一档**截止日 | 倒计时 |
| `status` | `open/pending/soon/closed` | 征集中 / 截止待公布 / 即将开放 / 已截止 | 状态标签 |
| `organizer` | 字符串 | 主办方（抄全） | 卡片副信息、详情 |
| `region` | 字符串 | 地区，如 中国·厦门 / 线上 | 详情 |
| `category` | 字符串 | 类别，如 AI短片 / AI影展 | 详情 |
| `topic` | `命题/自由投稿/空` | 是否命题 | 标签 |
| `fee` | 字符串 | 报名费；未核实写「未核实」，未公布写「官方未公布」，**不臆测** | 卡片 + 详情 |
| `prize` | 字符串 | 最高奖励，官网口径 | 卡片 + 详情 |
| `site` | URL | 主办方官网 | 详情 |
| `submit` | URL / `mailto:` | 投递入口，优先官方 | 详情主按钮 |
| `desc` | 文本 | 赛事说明（性质、主办方、形式、时间地点、要求） | 详情正文 |
| `notes` | 文本 | 档期备注、核实记录 | 详情折叠区 |
| `verified` | `ok/fixed/warn/none` | 核实状态 | 详情徽章 |
| `verifyNote` | 字符串 | 核实说明 | 详情徽章 |

### 2.2 字段清洗规则（构建时执行，任一不满足即报错退出，不发布坏数据）

1. `deadline` 必须是 `YYYY-MM-DD` 或空；格式不对 → 置空并在构建日志告警。
2. `grade` 必须在 `S/A/B/C` 内。
3. `status` 必须能由 `截止日期 + 征集状态` 推出；`已截止` 与未来日期冲突 → 以 `已截止` 为准并告警。
4. `site`/`submit` 必须是 `http(s)` 或 `mailto:`；出现聚合站域名（投奖、aitop100 等）→ 告警。
5. 赛事条数为 0 或骤降超过 30% → **中止构建**，避免把线上站点清空。
6. 每条赛事必须能生成一个可读的截止描述（日期或「待公布」）。

### 2.3 派生字段（前端计算，不落库）

- `daysLeft`：今天到截止日的天数（按本机日期）。
- `urgency`：`red` ≤3 天 / `amber` ≤7 天 / 其他无。
- `isFree`：报名费文本判定为免费。
- `hasCash`：最高奖励含现金金额。
- `cashCNY`：按固定汇率折算，仅用于比较。
- `forms`：作品形态（短片/短剧/长片/广告/MV/动画/公益），由名称、类别、说明匹配。

## 3. 页面功能规格

### 3.1 截止雷达（首页）

自上而下，**首屏必须看到赛事**：

1. **页头**：日期 + 一句话结论（例："今天有 3 个赛事即将截止，在征 115 个"）。
2. **关键数字条**（4 个，可点击跳筛选）：在征赛事数、7 天内截止数、S/A 级数、免费报名数。
3. **未来 14 天截止时间轴**：每天一列，按分级堆叠小色块，点某天展开当天截止的赛事列表；周末可选弱化。
4. **最近截止（列表，最多 8 条）**：紧凑行，含倒计时块、名称、标签、奖励、地区。
5. **值得投 · S/A 级**（卡片，最多 8 个）。
6. **零门槛 · 免费且有现金奖**（列表，最多 6 条）。
7. **新收录**（可选，若本次快照有新条目则显示）。

规则：不出现"我的赛事/我的投递/作品"任何内容。

### 3.2 全部赛事

- 视图：列表 / 卡片，切换状态记住。
- 搜索：多词（空格分隔，AND），命中高亮；输入防抖 250ms，**不打断输入焦点**。
- 筛选（每组可单选，互不冲突）：
  - 时间：全部在征 / 3 天内 / 7 天内 / 30 天内 / 截止待公布 / 含已截止
  - 分级：不限 / S+A / S / A / B / C
  - 条件：免费报名 / 有现金奖 / 命题 / 自由投稿 / 国内 / 海外
  - 形态：短片 / 短剧 / 长片 / 广告 / MV / 动画 / 公益
- 每个选项显示当前条件下可命中的数量；数量为 0 的选项弱化。
- 已选条件以标签形式集中展示，可单个移除，也可一键清空。
- 排序：截止最近 / 分级最高 / 奖金最高 / 名称。
- 筛选状态写入网址（可分享）；手机端筛选默认收起，点「筛选条件」展开并显示已选数量。
- 结果为空时给明确空状态与清空入口。

### 3.3 截止日历

- 月视图，周一为每周首日；每格显示当天截止的赛事（最多 3 条 + "还有 N 个"）。
- 格子的底色深浅反映当天截止数量；过去的日子加斜纹弱化。
- 范围切换：全部 / B 级以上 / 已截止关闭的排除。
- 导出 `.ics`：包含在征赛事的截止日，提前 3 天与当天各一个提醒。
- 日历下方给出本月截止清单，按日期分组。

### 3.4 数据洞察

- 未来 8 个月截止分布（按分级堆叠柱状）。
- 分级构成（环形 + 图例）。
- 门槛结构（免费/收费、现金奖/荣誉、命题/自由、国内/海外 四组对比条）。
- 作品形态分布（横向条，点击跳筛选）。
- 现金奖金排行（前 8，折算人民币，点击打开详情）。

### 3.5 今日简报

- 报头：日期、期号、一句话结论、4 个数字块。
- 分栏：今天/明天截止、2–3 天内、本周内（4–7 天）、30 天内的 S/A 级、免费且有现金奖。
- 操作：复制纯文本、复制 Markdown、打印/存 PDF。
- 打印样式：隐藏导航与按钮，只留文章。

### 3.6 知名电影节

- 卡片：名称、国家/城市、类别、每年举办时间（月份条）、最高奖、最新档期、备注。
- 可按类别筛选。

### 3.7 收录与分级

- 收录红线、分级模型（认可度 35% / 可信度 30% / 资源回报 20% / 成本 15%）。
- 分级卡片：S/A/B/C 各档说明与当前数量。
- 核实状态卡片：已核实 / 已更正 / 待确认 的数量与含义。
- 快捷键说明。
- **不出现任何数据来源站点的名称或链接**。

### 3.8 赛事详情（右侧抽屉，手机从底部弹出）

- 头部：分级色块、分级名称、赛事名、主办方与地区、倒计时（天/时/分/秒）。
- 核实状态卡片。
- 关键信息：最高奖励（含折算）、报名费、命题、类别、地区。
- 链接卡片：官网、（与官网不同时的）投递入口；邮箱投稿显示为"发邮件投稿"。
- 时间节点：从备注与说明里提取的关键日期轴（含"最终截止"）。
- 正文：赛事说明；备注（可折叠）。
- 底部操作：去投递（主）、加入日历提醒、复制信息、分享链接。
- 键盘：← → 切换上一个/下一个，Esc 关闭；关闭后焦点回到来源卡片。

## 4. 交互与无障碍

- 全局：`/` 或 `⌘K` 打开搜索面板（可搜赛事、电影节、页面、快捷操作）；`?` 打开快捷键帮助；`Esc` 关闭最上层浮层。
- 列表：`J`/`K` 上下移动，`Enter` 打开，`S` 收藏。
- 搜索面板：上下键选择、Enter 打开、输入即搜。
- 卡片与列表行可 Tab 聚焦（`tabindex="0"`），Enter 打开。
- 打开抽屉时背景设为 `inert`，关闭后恢复。
- 尊重 `prefers-reduced-motion`；深浅色跟随系统，可手动覆盖。
- 手机：底部标签栏（5 项），抽屉从底部弹出并带拖拽条，筛选收起。
- 所有收藏/隐藏操作都可撤销（Toast + 撤销按钮）。

## 5. 数据与构建

- 构建脚本读取赛事快照与电影节快照，执行第 2 节清洗规则，产出：
  - `public/data/data.js`（页面直接引用的数据）
  - `public/data/contests.json`（便于其他程序使用）
  - `public/deadlines.ics`（可订阅的截止日历）
  - `public/feed.xml`（RSS）
- 构建失败即中止，不覆盖线上产物。
- 每日自动构建：GitHub Actions 定时拉最新快照 → 构建 → 冒烟测试 → 发布 Pages。

## 6. 视觉与文案规范

- 风格：编辑式排版（editorial），暖纸白底 + 墨色文字 + 单一强调色（朱红），细线分隔，克制阴影；不使用大面积渐变或玻璃拟态堆叠。
- 中文字体栈优先系统中文字体，数字使用等宽字形并开启 tabular-nums。
- 文案：只用陈述句，不用感叹号营销语；不确定的信息一律写"待确认/未公布"，不写"疑似""据说"。
- 页脚只保留一句「截止日期与规则以主办方官网为准」，不出现数据来源站点。

## v7 新增：上新、时间线、分享卡片

### 上新与改期（数据）
- 构建时读取仓库里的全部历史快照（最多 45 份）逐日比对：某条赛事**第一次出现的快照日期**记为「收录日」（`added`）；截止日在前后两份快照间变化，记一条「改期」（`changes`，只保留最近 3 条）。
- 最早一份快照里已有的赛事视为基线，`added` 为空，**不冒充上新**。
- 赛事换了 ID 但名称相同，沿用原收录日，避免重复算上新。
- 「上新」标签：收录 3 天内显示；当天收录显示「今日上新」。

### 时间线 `#/timeline`
- **全景**：每个赛事一行，按截止日排序、按截止月份分组。横条从收录日画到截止日（收录前就开始的，左端渐隐），红色竖线是今天；空心圆点 = 收录日，菱形 = 截止日调整。左侧赛事名列固定，表头月份刻度固定。
  - 范围：30 天 / 60 天（默认）/ 半年 / 全部。筛选：分级、免费、近 7 天上新、含已截止；可搜索。条件写进网址。
  - 截止待公布的赛事不上轴，单独列在下方。
- **每日动态**：以今天为中心（过去 7 天 ~ 未来 30 天），按天列出「改期 / 上新 / 截止」三类事件，进入时自动定位到今天。
- 点任意一行打开详情；键盘 Tab + 回车可用。手机端横向可滑动，赛事名列缩窄。

### 首页
- 第一屏新增「今日截止 / 今日上新」双栏速览（各 5 条）+「生成今日分享卡片」入口；14 天条右上角加「完整时间线」入口。

### 今日简报与分享卡片 `#/brief`
- 口径：左栏「今日截止」，当天为空自动放宽为「3 天内截止」，再空放宽为「7 天内」；右栏「今日上新」，当天为空放宽为「近 3 天上新」，再空放宽为「近 7 天」。标题如实显示放宽后的名称。
- 左栏条目明显少于右栏时，用「随后截止」补齐左栏，左右高度对齐。
- 尺寸：竖版长图（默认，1080 宽，高随内容；底部附「本周还要截止」「截止日有调整」）、竖版 3:4（1080×1440）、横版 16:9（1920×1080）；浅色 / 深色。放不下的条目显示「还有 N 个 · 到网站查看全部」。
- 卡片不放二维码，只写网址（`siteUrl`，默认 GitHub Pages 地址，构建时可用 `SITE_URL` 覆盖）。
- 操作：保存图片（PNG）、复制图片、复制配文（与卡片同结构的文字版，带网址）；文字版也可复制纯文本 / Markdown / 打印。
- 验收：三种尺寸 × 两种配色，卡片内所有文字不越界、不重叠（测试会逐段测量）。

### 全部赛事
- 新增「上新」筛选（今日 / 近 3 天 / 近 7 天）与「最新收录」排序。
- 详情抽屉显示收录日期与截止日调整记录。

- **可执行性**：67 项浏览器交互 + 对抗测试全通过（含恶意数据、损坏本地存储、错乱时区、时钟拨到 2025/2027、非法 URL 参数、三尺寸两配色卡片文字逐段越界与重叠检测）；CI 冒烟测试全通过。
- **对比度**：浅 / 深两套配色下，新增的时间线、双栏、卡片工作台均达到 WCAG AA（正文 4.5:1、大字 3:1）。
- **降级**：数据为空、全部过期、浏览器不支持 Canvas / 剪贴板 / 下载时都有提示或占位，不白屏。
- **已知取舍**：卡片是 Canvas 位图，二维码不做（按需求只写网址）；已截止赛事在时间线默认隐藏，需勾「含已截止」。


## v7.1 对抗审查修订（2026-10-22）

审查覆盖：9 个「今天」时刻（含 23:59:30 / 00:00:30 / 跨年 / 闰日 / 早于快照）、3 个极端时区、空数据、字段缺失、全量「今天截止 / 今天上新 / 待公布」、1 条数据、6 倍数据量、超长文本（中文 240 字 + 无空格英文长串）、脏字段、注入字符串、恶意网址参数、本地存储损坏 / 被禁用、Canvas 不可用、10 种卡片数据形态 × 3 尺寸。

修掉的问题：

1. **简报出现「还剩 null 天」**：截止待公布 / 已截止的条目落在「随后截止 / 本周还要截止」里时，剩余天数写作 null。已改为「截止待公布」「已截止 · x月x日」。同时「免费且有现金奖 · 时间充裕」不再收截止待公布的赛事。
2. **网址参数是 `__proto__` / `constructor` 时读到原型属性**：排序显示 undefined、卡片生成失败。已加 `own()` 只读自有属性，参数解析过滤这三个键、单值截断 200 字。
3. **浏览器禁用本地存储时整站白屏**：读写 local storage 全部包了保护（隐私模式、企业策略）。
