# AI赛事助手 · 设计规范（v6）

## 1. 设计原则

1. **信息优先**：先让人看清"有哪些赛事、什么时候截止"，装饰一律让位。
2. **一个强调色**：全站只有一个强调色，用于可点击与关键数字；分级用固定的四色，不与其他用途混用。
3. **细线而非重框**：分隔用 1px 细线，卡片不用粗边框与浓阴影。
4. **密度分层**：列表密、卡片疏；同一屏不出现两种以上的节奏。

## 2. 设计令牌

### 2.1 颜色（浅色）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#FAF8F4` | 页面底色（暖纸白） |
| `--surface` | `#FFFFFF` | 卡片 |
| `--surface-2` | `#F4F1EA` | 次级块、输入框 |
| `--ink` | `#16181C` | 主文字 |
| `--ink-2` | `#3B4048` | 正文 |
| `--ink-3` | `#6A7280` | 辅助文字 |
| `--ink-4` | `#98A0AC` | 最弱信息 |
| `--line` | `#E6E1D8` | 分隔线 |
| `--line-2` | `#D6D0C4` | 强调分隔 |
| `--accent` | `#C2410C` | 强调（朱红）：链接、主按钮、关键数字 |
| `--red` | `#C2410C` | 3 天内截止 |
| `--amber` | `#A16207` | 7 天内截止 |
| `--green` | `#15803D` | 免费等正向信息 |

分级固定色：S `#B91C1C`、A `#C2410C`(描边样式)、B `#4338CA`、C `#6B7280`。

### 2.2 颜色（深色）

`--bg #0C0D10`、`--surface #15171C`、`--surface-2 #1D2026`、`--ink #ECEDF0`、`--ink-3 #A2A9B4`、`--line rgba(255,255,255,.09)`、`--accent #F97316`。
深色下所有正文对比度 ≥ 4.5:1；分级色同步提亮（S `#F87171`、A `#FB923C`、B `#A5B4FC`、C `#9CA3AF`）。

### 2.3 字体与字号

- 正文 `14px/1.65`；辅助 `12.5px`；微文字最小 `11px`（仅限标签）。
- 标题阶梯：页面标题 30/24（桌面/手机）、区块标题 16、卡片标题 15、行标题 15。
- 数字统一 `font-variant-numeric: tabular-nums`，倒计时等宽。
- 字重只用 400 / 500 / 600 / 700 四档，避免过粗。

### 2.4 间距与圆角

- 间距基数 4：常用 8 / 12 / 16 / 20 / 24 / 32。
- 圆角：标签 999、输入框与按钮 10、卡片 14、面板 18。
- 卡片内边距 16（移动）/ 18（桌面）。

## 3. 组件规范

| 组件 | 规范 |
|---|---|
| 按钮 | 高 38（主）/ 32（次）；主按钮实心强调色，次按钮细边框；同一区域最多一个主按钮 |
| 标签 | 高 22，圆角 999，11.5px；颜色仅用语义色（免费/现金/命题/状态） |
| 分级徽标 | 22×22，圆角 6，白字，固定四色 |
| 倒计时 | 数字 32–40px 等宽，单位 11px；分组之间用细冒号 |
| 输入框 | 高 40，`--surface-2` 底，聚焦时 1px 强调色 + 3px 淡色外圈 |
| 列表行 | 高 ≥72；左侧倒计时块 72 宽；右侧图标按钮 32 |
| 卡片 | 顶部 100–120 高的分级色块（含剩余天数），下部正文；悬停仅轻微上浮与描边加深 |
| 抽屉 | 宽 600（桌面）/满宽（手机）；头部按分级配色；底部操作固定 |
| 空状态 | 居中图标 + 一句说明 + 一个出口动作 |
| Toast | 底部居中，深色底，带撤销按钮，3 秒自动消失 |

## 4. 布局

- 桌面：左侧 240px 固定导航 + 主区最大 1200px。
- 折叠点：1200（KPI 变 2×2）、860（侧栏变抽屉、底部标签栏出现）。
- 手机：内容左右边距 14，底部为悬浮标签栏预留 96 的安全距离。

## 5. 动效

- 仅三类：页面切换淡入上移 300ms、卡片悬停 200ms、抽屉/弹窗 380ms。
- 数字滚动仅用于首屏 KPI，700ms 缓出。
- `prefers-reduced-motion` 下全部关闭。

## 6. 文案规范

- 客观陈述，不用"重磅/必投/速冲"。
- 不确定标注：`待确认`、`未公布`、`未核实`，三种含义不同不可混用。
- 日期格式：界面用 `10月20日`，数据与文件用 `2026-10-20`。
