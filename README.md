# AI赛事助手

AI 视频 / AI 影像赛事的截止追踪站。数据来自 [ai-film-contests-tracker](https://github.com/YIJUEYIJUE/ai-film-contests-tracker)，每天自动更新。纯静态、零依赖，可以免费部署到 GitHub Pages。

## 页面

| 页面 | 能做什么 |

**影片与赛事匹配**：从赛事说明里读出时长、仅限学生、中英字幕、首映、竖屏、AI 占比、地区和机构限制、命题等要求，再对照当前影片的资料，显示「符合 / 需要确认 / 不符合」。全部赛事页可以筛选「适合当前影片」。

**赛事详情**（右侧抽屉，手机上从底部弹出）：

- 投递进度、结果（审核中 / 入围 / 获奖 / 未入围 / 撤回）、投稿详情（单元、平台、提交日期、费用、确认编号、影片版本、回执链接），全部自动保存
- 去投递（邮箱投稿会直接打开邮件）、日历提醒、复制信息、分享链接
- 上下键切换上一个 / 下一个

**v4 新增**：
- **今日待办**：首页根据投递计划、影片资料和截止时间，自动列出今天该做的事
- **投递清单**：每个计划里的赛事会按要求生成材料清单，从影片资料能确认的项自动打勾
- **赛事对比**：最多同时对比 3 个赛事，逐项高亮最优的一个

- **可安装、可离线**：支持安装到桌面或手机主屏，断网也能打开
- 页面转场动画、数字滚动、鼠标跟随光效、滚动进度条、回到顶部；更多快捷键：`?` 帮助、`C` 加入对比、`G` 加 `H/C/F/T/B/L/I` 快速跳转

**其他**：
- 深色 / 浅色 / 跟随系统；手机端有悬浮底部标签栏
- 所有标记都可以撤销；多个标签页之间自动同步
- 快捷键：`/` 或 `⌘K` 全局搜索，`J`/`K` 上下移动，`Enter` 打开，`S` 标记想投，`Esc` 关闭

## 本地运行

```bash
python3 -m http.server -d public 8080   # 打开 http://localhost:8080（包里已带数据）
python3 scripts/build.py                # 拉最新数据重新构建（需联网）
npm i && npm test                       # 冒烟测试
```

## 部署到 GitHub Pages（每天自动更新）

1. `bash push.sh https://github.com/<你的账号>/<仓库>.git`
2. 进入仓库 Settings → Pages，把 Source 选成 **GitHub Actions**。
3. 进入 Actions，手动运行一次 `build-and-deploy`。

之后每天北京时间 08:05 自动更新。发布后还有两个订阅地址：
- `/deadlines.ics`：日历订阅
- `/feed.xml`：RSS

## 数据修正

`scripts/overrides.json` 按 `record_id` 维护对原始数据的修正：
- `fix`：用官网信息覆盖原字段
- `verify`：核实状态，`ok` 已核实 / `fixed` 已更正 / `warn` 待确认

每次构建时会自动应用，所以上游数据更新后，你的修正也不会丢。

## v5 · 审查与打磨

用真实浏览器（Chromium）逐页截图，在电脑浅色、手机深色两种情况下做了视觉评审，并修复了发现的问题：

- 修复手机「全部赛事」筛选标签被挤成竖排、和数字重叠的问题：筛选改为可展开的「筛选条件」按钮
- 首页主卡片不再有大块空白：加了赛事简介、4 格关键信息和距截止的时间进度条；右侧数据卡片恢复为两列两行
- 去掉屏幕底部残留的对比栏白色半圆
- 赛事卡片顶部背景大字调淡，不再压住文字；灰色卡片加深，白字清楚了
- 详情：顶部按钮分组并显示「第几 / 共几个」；核实状态改成卡片样式；官网改成链接卡片；底部按钮带文字；内容不再被底栏挡住
- 深色模式调亮文字；手机上不再显示电脑快捷键提示
- 键盘：Tab 键可以选中赛事卡片，回车打开；关闭详情后回到原来的位置；打开详情时，后面的页面不会被误点
- 在「我的影片」输入时不再整页刷新，焦点不会丢

测试：`npm test`（76 项）；另外在真实浏览器里跑了 35 项交互测试（点击、拖拽、键盘、手机手势、深浅色、各页面无横向溢出）。
