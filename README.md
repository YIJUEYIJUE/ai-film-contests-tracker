# AI 影像赛事追踪库

个人维护的 **AI 视频/影像/生成类赛事投递追踪库**，含两部分：

## `data/` — 赛事表（快照 2026-09-29：**104 条**）

数据源为飞书多维表格（Base `J0KPbWdLVaim7csALvjccfP7nwZ` / 表 `tblCWZjMO07OvOnN`），每日巡检更新。

- `contests_2026-09-29.json` — 全量结构化数据
- `contests_2026-09-29.md` — 可读清单（按截止日排序）

**字段说明**
| 字段 | 说明 |
|---|---|
| 截止日期 | 该届最终投稿截止（多档期取最后一档 final，已逐条对照官方页核实） |
| 征集状态 | 开放征集中 / 即将开放 / 待公布 / 已截止 |
| 分级 | S/A/B/C（认可度35%+可信度30%+资源回报20%+成本15% 加权；首届无交叉验证封顶 A） |
| 命题 | 自由投稿 / 命题 |
| 官网 | 主办方自有域名优先；确无独立官网时填平台直达页并备注 |
| 报名费 / 最高奖金 | 官方页核实；未公布的如实标注 |

**收录红线**：仅收 AI 视频/影像类（AI 音乐类不收）；官网必须官方站；只收有明确在征窗口的赛事；过期 >7 天清理（删前逐条核实是否延期）。


## `sources/` — 信源主库（快照 2026-09-29：**65 条**）

赛事线索的来源账号（公众号/小红书/官网/平台等），每条信源 = 一个账号主体，与飞书 Base 内「AI赛事信源」表同步。字段：名称/平台/简介/小红书号/主页链接/IP属地/发布时间/代表内容/备注。含采集 SOP（`SOP.md`）。

## `festivals/` — 全球知名电影节（快照 2026-09-29：**24 条**）

FIAPF 权威电影节体系：电影节名称、国家/城市、类别（A类/B类/非竞赛型等）、每年举办时间、最高奖、最新档期。


**飞书信源表**（`feishu_sources_*.json/md`）：飞书 Base 内「AI赛事信源」表的同步快照（65 条，字段：名称/平台/简介/小红书号/主页链接/IP属地/发布时间/代表内容/备注），与本地采集底表（sources_raw）同源，结构更规整。


## 站点（CineCall 影赛雷达）

本仓同时承载赛事展示站：`site` 相关文件（`public/ scripts/ tests/ package.json`）由 GitHub Actions 每天 08:05 用本仓最新快照构建并发布到 Pages：
**https://yijueyijue.github.io/ai-film-contests-tracker/**

- `public/` 站点目录（构建产物已随仓附带）
- `scripts/build.py --local .` 构建命令（读本仓 data/ festivals/ sources/）
- `.github/workflows/deploy.yml` 定时构建 + 冒烟测试 + 发布

## 更新方式

以日期为文件名追加快照（如 `contests_2026-09-29.json`），历史快照保留可追溯。
