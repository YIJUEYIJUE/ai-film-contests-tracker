数据源为飞书多维表格（Base `J0KPbWdLVaim7csALvjccfP7nwZ` / 表 `tblCWZjMO07OvOnN`），每日巡检更新。

- `contests_2026-09-29.json` — 全量结构化数据
- `contests_2026-09-29.md` — 可读清单（按截止日排序）

**字段说明**
| 字段 | 说明 |
|---|---|
| 截止日期 | 该届最终投稿截止（多档期取最后一档 final，已逐条对照官方页核实） |
| 征集状态 | 开放征集中 / 即将开放 / 待公布 / 已截止 |
| 分级 | S/A/B/C（认可度35%+可信度30%+资源回报20%+成本15% 加权；首届无交叉验证封顶 A） |
| 命题 | 自由投稿 / 命题 |
| 官网 | 主办方自有域名优先；确无独立官网时填平台直达页并备注 |
| 报名费 / 最高奖金 | 官方页核实；未公布的如实标注 |

**收录红线**：仅收 AI 视频/影像类（AI 音乐类不收）；官网必须官方站；只收有明确在征窗口的赛事；过期 >7 天清理（删前逐条核实是否延期）。

## `sources/` — 信源主库（快照 2026-09-29：**64 个信源**）

赛事线索的来源账号（公众号/小红书/官网/平台等），每条信源 = 一个账号主体。含采集 SOP。

## 更新方式

以日期为文件名追加快照（如 `contests_2026-09-29.json`），历史快照保留可追溯。
